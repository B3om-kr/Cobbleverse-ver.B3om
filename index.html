지역 해금과 전설 구조물

범스 서버는 Cobbleverse의 지역 진행 구조를 유지합니다. 관동 → 성도 → 호연 → 신오 순서로 콘텐츠가 열리며, 아직 해금되지 않은 지방의 구조물은 미리 강제로 활성화하지 않습니다.

신오 주요 전설 구조물: Lake Acuity / Lake Valor / Lake Verity / Stark Mountain / Turnback Cave.

서버 로그에서 미해금 지방의 구조물 태그 관련 경고가 보일 수 있으나, 해당 지방 데이터팩이 아직 활성화되지 않은 단계라면 진행상 정상 범주로 취급합니다. 지역이 해금된 뒤 서버 재시작 및 새 청크 탐험을 권장합니다.

M&L 사용 팁

현재 서버는 Myths & Legends 1.9.0 + 범스 커스텀 데이터팩 v3 (Weight 0.8) 조합을 사용합니다.

키 아이템을 넣거나 뺀 뒤 스폰풀 반영은 M&L의 인벤토리 스캔 주기에 따라 약간 늦을 수 있습니다.

관리자 테스트: /mal checkinventory → /checkspawn ultra-rare

정상 동작 기준: 키 아이템 보유 시 대상 포켓몬이 Ultra-Rare 후보에 나타나고, 아이템 제거 후 다시 스캔하면 후보에서 사라집니다. v2에서는 Cobbleverse 정식 루트와 충돌하던 M&L 내장 스폰 8종도 비활성화해 구형 preset 오류를 제거했습니다.
